# Sierra Games Backend

Spring Boot API backend for the Sierra Games application.

## 🚀 Future Implementation

This directory will contain:

- **Spring Boot Application**: REST API endpoints
- **MySQL Integration**: Database connectivity with JPA
- **Authentication**: Spring Security implementation
- **Game Management**: CRUD operations for game data
- **File Upload**: Media management for screenshots/videos
- **Search & Filtering**: Advanced query capabilities

## 🛠️ Technology Stack (Planned)

- **Java 17+**: Modern Java features
- **Spring Boot 3.x**: Latest Spring framework
- **Spring Security**: Authentication and authorization
- **Spring Data JPA**: Database operations
- **MySQL 8+**: Relational database
- **Maven**: Build tool and dependency management
- **JUnit 5**: Testing framework

## 📋 Development Setup (Future)

```bash
# Install dependencies
mvn clean install

# Run development server
mvn spring-boot:run

# Run tests
mvn test

# Build for production
mvn clean package
```

## 🔗 API Endpoints (Planned)

- `GET /api/games` - List all games
- `GET /api/games/{id}` - Get game details
- `POST /api/games` - Create new game
- `PUT /api/games/{id}` - Update game
- `DELETE /api/games/{id}` - Delete game
- `GET /api/series` - List game series
- `POST /api/auth/login` - User authentication
